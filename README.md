# Neumorphic-Sliding-Login-Signup-Form

A modern and responsive Login & Signup Form built using HTML, CSS, and JavaScript with a clean Neumorphic UI design and smooth sliding animations.

## 🚀 Project Overview

This project demonstrates a stylish authentication interface with two interactive panels: Login and Sign Up. Users can smoothly switch between the login and registration forms using sliding transitions.

The design follows the Neumorphism UI concept, featuring soft shadows, subtle highlights, rounded elements, and a minimal interface.

## ✨ Features

- Modern Neumorphic UI design
- Sliding Login and Signup panels
- Smooth CSS transitions and animations
- Interactive buttons and form elements
- Clean and minimal layout
- Responsive design
- Lightweight and fast loading
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling, Neumorphic effects and animations
- JavaScript – Interactive sliding functionality

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ARAVINDKUMARGS/Neumorphic-Sliding-Login-Signup-Form.git
```

### 2. Navigate to the Project Folder

```bash
cd Neumorphic-Sliding-Login-Signup-Form
```

### 3. Run the Project

Open `index.html` in your web browser.

No additional dependencies or installations are required.
